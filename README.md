# Тёплый Хвост — сайт ветеринарной клиники

Учебный индивидуальный проект (лицей ФГБОУ ВО РГУПС, 2026/2027 учебный год).

**Тема:** разработка сайта ветеринарной клиники на основе анализа российских аналогов.

## Что умеет сайт
- Услуги с переключателем «Для собак / Для кошек»
- Прайс с поиском и фильтром по категориям
- Окно записи на приём и форма обратного звонка с проверкой полей и согласием на обработку данных
- Отзывы (хранятся в браузере посетителя)
- Врачи, акции, статьи, вопросы и ответы, контакты
- Адаптивная вёрстка: компьютер, планшет, телефон

## Технологии
HTML, CSS и JavaScript без библиотек и фреймворков. Внешние шрифты и скрипты не подключаются, интернет для работы не нужен.

## Структура
```
index.html     — содержимое страницы
css/style.css  — оформление
js/main.js     — поведение (меню, вкладки, прайс, формы, отзывы)
img/           — логотип и изображение первого экрана
```

## Как запустить
Скачать репозиторий и открыть `index.html` в браузере. Заявки никуда не отправляются: у проекта нет серверной части.

## Как заменить изображение на первом экране
Положить свой файл в `img/hero.png`.

## Об авторстве
Структура сайта обоснована сравнительным анализом шести сайтов российских ветеринарных клиник (чужой код и тексты не копировались). Код подготовлен с помощью ИИ-ассистента Claude (Anthropic) и разобран автором проекта. Имена врачей, цены, адрес и телефоны на сайте — учебные примеры.
